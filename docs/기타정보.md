## 2. 프로필 상세 선택 항목 (Profile Details)

보호자가 반려동물의 특징을 쉽고 정확하게 입력할 수 있도록 서술형 선택지로 구성합니다.

### 2.1 성향 (Personality)
* **활동성 (Activity Level)**
    * `ENERGIZER`: 에너자이저 (지치지 않는 체력, 격렬한 움직임 선호)
    * `ACTIVE`: 활발함 (움직이는 것을 좋아하고 호기심이 많음)
    * `NORMAL`: 보통 (적당히 놀고 적당히 휴식함)
    * `CALM`: 얌전함 (차분하고 정적인 활동 선호)
    * `STATIC`: 매우 정적인 편 (움직임이 적고 주로 휴식을 취함)
* **사회성/친화력 (Socialization)**
    * `SOCIAL`: 모두의 친구 (사람과 동물 모두에게 먼저 다가감)
    * `PEOPLE_ONLY`: 사람 중심 (사람은 좋아하지만 동물 친구는 무관심)
    * `SELECTIVE`: 선택적 친화력 (익숙한 대상이나 마음에 드는 상대에게만 다가감)
    * `SHY`: 낯가림 있음 (경계심이 있고 친해지는 데 시간이 필요함)
    * `INDEPENDENT`: 독립적인 편 (혼자 있는 시간을 즐기며 접촉을 피함)
* **훈련 상태 (Training Status)**
    * `PROFESSIONAL`: 전문 교육 수료 (행동 교정 등 전문 과정 이수)
    * `BASIC`: 기본 매너 숙지 ('앉아', '기다려', 배변 등 기초 가능)
    * `TRAINING`: 현재 교육 중 (새로운 규칙을 배워가는 단계)
    * `FREE_SPIRIT`: 자유로운 영혼 (특별한 훈련 없이 본능에 충실함)
* **소음 수준 (Noise Level)**
    * `VOCAL`: 표현이 풍부함 (자주 짖거나 울음소리로 의사 표현)
    * `NECESSARY`: 필요할 때만 (경계 상황이나 요구 사항이 있을 때만 소음을 냄)
    * `QUIET`: 거의 없음 (평소 매우 조용하며 소리를 내는 일이 드묾)

### 2.2 관심사 (Interests)
* **장난감 놀이 (Toy Play)**: 장난감 마니아 / 즐겨 노는 편 / 보통 / 관심 낮음
* **야외 활동 (Outdoor Activity)**: 산책 중독 / 산책을 즐김 / 적당히 즐김 / 실내파
* **스킨십 (Physical Touch)**: 애교쟁이 / 스킨십 선호 / 적당히 수용 / 개인 공간 중시
* **친구 관계 (Friendship)**: 적극적인 사교가 / 매너 있는 관계 / 조심스러운 만남 / 외골수
