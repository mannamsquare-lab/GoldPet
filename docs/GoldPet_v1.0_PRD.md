# GoldPet_v1.0_PRD.md

## 1. 프로젝트 개요
GoldPet은 반려동물의 산책, 프로필 관리, 커뮤니티, AI 프로필 생성, 친구 매칭, 채팅 등 반려동물 중심의 통합 서비스를 제공하는 모바일 앱이다. Flutter로 개발되며 Android와 iOS에 배포된다.

## 2. 타겟 사용자
- 반려견/반려묘를 키우는 사용자
- 산책 친구 또는 펫 플레이데이트를 찾는 사용자
- 반려동물 중심 커뮤니티 활동을 원하는 반려인
- AI 기반 프로필 생성 및 기록 관리 기능을 이용하고 싶은 사용자

## 3. 핵심 가치
1. 반려동물 중심 라이프로그
2. 위치 기반 산책 추천 및 기록
3. AI 기반 프로필 이미지/영상 생성
4. 친구 매칭 및 실시간 채팅
5. 커뮤니티 기반 정보 공유
6. Gold 화폐 기반 인앱 경제

---

# 4. 주요 기능

## 4.1 회원 기능
### 🔹 회원가입 흐름
1. 사용자가 이메일 또는 SNS(카카오/네이버/구글/애플)로 가입 선택  
2. 약관 동의(필수/선택)  
3. 기본 사용자 프로필 입력(닉네임·성별·생년)  
4. 위치 접근 권한 요청  
5. "반려동물 등록" 화면으로 이동  
6. 회원가입 즉시 3,000 Gold 지급  

### 🔹 로그인 흐름
- 기존 SNS 인증 → JWT 발급  
- 이메일 로그인 시 비밀번호 확인  
- 자동 로그인 토큰 갱신  

---

## 4.2 반려동물 프로필 관리
### 🔹 프로필 생성 흐름
1. 이름, 종(개/고양이), 품종 선택  
2. 나이/생일, 체중 입력  
3. 성격 태그 선택(활발/조용/사교적 등)  
4. 건강 특이사항 입력  
5. 사진 업로드  
6. 완료 후 메인 홈으로 이동  

### 🔹 기능 상세
- 반려동물 여러 마리 등록 가능  
- 프로필 수정 및 삭제 가능  

---

## 4.3 위치 기반 기능
### 🔹 위치 설정 흐름
1. 앱 설치 후 위치 접근 권한 허용 요청  
2. 지도 기반 주요 활동 지역 선택  
3. 산책 반경 설정(1km/3km/5km)  
4. 추천 코스 자동 생성  

### 🔹 산책 코스 추천
- 인기 산책로  
- 주변 반려동물 활동 많은 장소  
- 사용자 취향 기반 AI 최적 코스  

---

## 4.4 산책 기능
### 🔹 산책 기록 흐름
1. “산책 시작” 버튼 클릭  
2. GPS 기반 실시간 추적 시작  
3. 위치 기반 Spot 기능 활성화  
4. 사진 촬영 시 해당 위치에 Spot 생성  
5. 산책 종료 → 통계 계산  
6. 기록 저장 및 공유 가능  

### 🔹 저장되는 정보
- 전체 이동 거리  
- 산책 시간  
- 칼로리 소모량(사용자/반려동물)  
- GPS 궤적  
- Spot 사진 및 메모  

---

## 4.5 친구 찾기 & 매칭
### 🔹 친구 찾기 흐름
1. 추천 리스트 또는 필터 선택  
2. 상대 프로필 조회  
3. “좋아요” 버튼 선택 시 Gold 차감 여부 확인  
4. 상대방에게 알림 전송  
5. 상대도 좋아요 시 → 매칭 성립  

### 🔹 필터 조건
- 종, 품종  
- 성별  
- 나이  
- 중성화 여부  
- 활동 지역  
- 산책 스타일  
- 반려동물 성격  

### 🔹 매칭 후 흐름
- 자동 1:1 채팅방 생성  
- 알림 발송  
- 프로필 자동 노출 제한  

---

## 4.6 채팅 시스템
### 🔹 1:1 채팅 흐름
1. 매칭 성공 → 채팅 활성화  
2. 텍스트/사진 전송  
3. 산책 기록 공유 기능  
4. 차단/신고 기능 포함  

### 🔹 그룹 채팅 흐름
- 산책 모임 개설 → 참여자 초대  
- 다중 사용자 채팅 가능  

### 🔹 AI 펫 챗봇 흐름
1. 유저의 반려동물 정보 로드  
2. 성격 기반 말투 자동 설정  
3. 건강/사료/운동 추천 가능  
4. 산책 기록 요약 제공  

---

## 4.7 AI 펫 프로필 생성
### 🔹 흐름 상세
1. 반려동물 사진 업로드  
2. 색상/특징/성격 입력  
3. Pixar/애니/디즈니 스타일 선택  
4. Gold 사용 여부 표시  
5. 생성 요청 → AI 서버 처리  
6. 이미지 또는 3~5초 영상 반환  
7. 저장 또는 공유  

---

## 4.8 커뮤니티
### 🔹 게시글 작성 흐름
1. 카테고리 선택  
2. 텍스트 입력  
3. 사진 최대 10장 업로드  
4. 해시태그 선택  
5. 등록 → 피드 반영  

### 🔹 커뮤니티 기능
- 좋아요  
- 댓글  
- 신고  
- 인기글 페이지(조회·반응 기반)  

---

## 4.9 Gold 시스템
### 🔹 기본 골드 지급
- 회원가입 시 3,000 Gold 자동 제공  

### 🔹 Gold 충전 흐름
1. 결제 패키지 선택  
2. 스토어 결제  
3. 서버에서 영수증 검증  
4. Gold 반영  
5. 결제 이력 저장  

### 🔹 Gold 사용처
- AI 프로필 생성  
- 추가 좋아요  
- 커뮤니티 프리미엄 글  
- 매칭 부스터
