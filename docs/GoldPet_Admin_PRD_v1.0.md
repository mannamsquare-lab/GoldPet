# GoldPet Admin System – PRD v1.0

**Date:** 2025-11-20
**Version:** v1.0
**Target:** GoldPet 운영팀, CS팀, 마케팅팀
**Based on:** GoldPet Final PRD v2.1 & Supplement v1.0

---

## 1. 개요 (Overview)

### 1.1 목적
본 시스템은 GoldPet 서비스의 안정적인 운영, 악성 유저 제재, 고객 문의(CS) 대응, 콘텐츠 관리 및 지표 모니터링을 위한 **통합 웹 어드민(Web Admin)**이다.

### 1.2 주요 목표
1.  **신속한 CS 대응:** 사용자 정보 및 로그 조회, Gold 오지급 처리 등 실시간 대응 환경 구축.
2.  **리스크 관리:** 악성 유저(어뷰징, 성인물 업로드 등)의 빠른 식별 및 제재(Ban).
3.  **데이터 기반 운영:** 주요 지표(DAU, 매출, 산책 현황) 시각화.
4.  **LBS 데이터 관리:** 장소(Place) 데이터 및 추천 친구 로직 관리를 위한 데이터셋 정비.

## 3. 상세 기능 명세 (Feature Specifications)

### 3.1 대시보드 (Dashboard)

* **목적:** 서비스 건강 상태를 한눈에 파악.
* **주요 지표(Today/Total):**
    * **User:** 신규 가입자, DAU, 탈퇴자 수.
    * **Walk:** 오늘 생성된 산책 기록 수, 총 산책 거리.
    * **Economy:** 결제 매출액, Gold 소모량(AI/아이템).
    * **Risk:** 처리 대기 중인 신고 건수.
* **차트:** 최근 7일/30일 트렌드 그래프.

### 3.2 회원 관리 (User Management)

#### 3.2.1 회원 상세 조회
* **검색:** User ID, 이메일, 닉네임, 전화번호 뒷자리.
* **상세 정보 탭:**
    * **기본 정보:** 가입일, 마지막 접속일, 디바이스 정보, 앱 버전.
    * **펫 정보:** 등록된 펫 리스트 및 상세 프로필.
    * **자산:** 보유 Gold (유료/무료 구분 표시).
    * **활동 요약:** 총 산책 거리, 매칭 수, 작성 글 수.
* **Action:**
    * 비밀번호 초기화 (이메일 발송).
    * 강제 로그아웃 (토큰 만료 처리).

#### 3.2.2 회원 제재 (Ban)
* **기능:** 특정 회원의 활동을 정지시킴.
* **유형:**
    * **기간 정지:** 1일 / 3일 / 7일 / 30일.
    * **영구 정지:** 서비스 이용 불가.
* **입력 항목:** 제재 사유(선택), 상세 메모(필수 - CS 대응용).

### 3.3 신고 및 콘텐츠 관리 (Reports & Moderation)

#### 3.3.1 신고 처리 프로세스
1.  **리스트:** 상태가 '접수(PENDING)'인 건 노출. (신고 유형, 신고자, 대상자 표시)
2.  **상세:**
    * 채팅 신고 시: 신고 시점 전후 대화 로그(Text) 또는 이미지 표시.
    * 게시글/댓글 신고 시: 원본 콘텐츠 표시.
3.  **처리(Action):**
    * **기각:** 무고하거나 문제없음.
    * **승인(삭제):** 콘텐츠 삭제 처리.
    * **승인(삭제+제재):** 콘텐츠 삭제 및 작성자 제재 팝업 연동.

#### 3.3.2 NSFW 이미지 검수 (옵션)
* AI(Rekognition 등)가 '주의' 판정을 내린 이미지를 사람이 최종 확인하여 삭제/공개 결정.

### 3.4 Gold 및 결제 관리 (Economy)

#### 3.4.1 Gold 수동 지급/회수
* **목적:** 이벤트 보상 지급, 시스템 오류 보상, 오지급 회수.
* **필드:** 대상 User ID, 금액(+/-), **사유(카테고리 및 텍스트 필수)**.
* **로직:**
    * 차감 시: `무료 Gold` -> `유료 Gold` 순서로 차감(Supplement 정책 반영).
    * 지급 시: `무료 Gold`로 지급을 기본으로 함 (유료 지급 시 별도 권한 필요).

#### 3.4.2 결제 내역 조회
* Store(Google/Apple) 영수증 ID로 조회.
* 환불 처리 상태 동기화 기능.

### 3.5 산책 및 지도 데이터 관리 (LBS)

#### 3.5.1 장소(Place) 관리
* **리스트:** 등록된 펫 프렌들리 장소 목록.
* **등록/수정:**
    * 장소명, 카테고리(공원, 카페 등), 주소.
    * **좌표(위도/경도):** 지도 핀 선택 기능 또는 좌표 직접 입력.
    * 설명 및 이미지 URL.
* **일괄 업로드:** Excel/CSV 템플릿을 이용한 대량 등록 기능.

#### 3.5.2 산책 어뷰징 모니터링
* 비정상적인 속도(예: 30km/h 이상)나 이동 거리가 기록된 산책 로그 필터링.
* 해당 기록 '비공개' 처리 또는 '랭킹 제외' 처리 기능.

### 3.6 게이미피케이션 관리

* **챌린지 관리:**
    * 제목, 기간(Start~End), 목표(거리/횟수), 보상(Gold/뱃지) 설정.
    * 상태 변경 (예정 -> 진행중 -> 종료).
* **뱃지 관리:**
    * 신규 뱃지 이미지 등록 및 코드 발급.

### 3.7 서비스 운영 관리

* **공지사항/이벤트:**
    * 제목, 본문(에디터), 노출 기간 설정.
    * 팝업 노출 여부 체크.
* **앱 버전 관리:**
    * Android/iOS 최신 버전 및 **강제 업데이트 최소 버전** 설정 (구버전 API 호환성 문제 시 차단용).

## 4. 비기능 요구사항 (Security & NFR)

### 4.1 접근 제어 (Access Control)
* **IP 화이트리스트:** 사내 IP 또는 특정 VPN IP에서만 Admin 페이지 접속 허용.
* **계정 권한 분리 (RBAC):**
    * `Super Admin`: 모든 권한 (계정 생성, Gold 유료 지급 포함).
    * `Operator`: 회원 조회, 신고 처리, 공지 사항 등록.
    * `Viewer`: 대시보드 및 지표 조회만 가능.

### 4.2 감사 로그 (Audit Log)
* 관리자의 **모든 데이터 변경 행위(C/U/D)**는 로그로 기록되어야 함.
    * *Who:* 관리자 ID
    * *When:* 일시
    * *What:* 대상 User ID, 변경 전 데이터, 변경 후 데이터
    * *Why:* 사유 (입력된 경우)
* 특히 **Gold 지급/차감** 및 **회원 개인정보 조회** 로그는 별도 강조 및 영구 보관.
