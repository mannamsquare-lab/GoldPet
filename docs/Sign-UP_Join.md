1. SNS 회원 가입 및 로그인
    네이버, 카카오톡, 애플, 구글 로그인

    1. 각 SNS 로그인 시 받은 정보를 파싱한 후 DB 에 존재하는지 체크
    2. DB 에 존재하지 않는다면, DB 에 저장
        2-1. DB 에 저장 후 약관 동의 화면으로 이동
        2-2. 약관 동의 화면에서 약관 동의 후 부가 정보 입력 화면으로 이동
        2-3. 부가 정보 (이름, 생년월일, 성별, 휴대폰번호) 입력 후 회원가입 완료
    3. DB 에 존재한다면, 로그인

2. 일반 회원 가입 및 로그인
    1. 약관 동의 화면으로 이동
    2. 약관 동의 후 필수 정보 입력 화면으로 이동
    3. 필수 정보 (아이디, 비밀번호, 이름, 생년월일, 성별, 휴대폰번호) 입력 후 회원가입 완료
    4. 아이디, 닉네임은 중복 체크 필수
